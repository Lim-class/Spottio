🏗️ Schema Firestore Aggiornato (NoSQL)

🔥 Firestore Root
├── 📁 users (Doc ID: uid)
│    ├── username: string
│    ├── userPfUri: string
│    ├── isVerified: boolean
│    └── chatBackgroundColor: string
│
├── 📁 ColoriSfondo (Doc ID: auto)
│    ├── hex: string
│    └── nome: string
│
├── 📁 chat_previews (Doc ID: conversationId o groupId)
│    ├── isGroup: boolean
│    ├── groupId: string [Opzionale]
│    ├── groupName: string [Opzionale]
│    ├── groupAvatarUrl: string [Opzionale]
│    ├── participants: array<string>
│    ├── lastMessage: string (AES)
│    ├── lastSender: string
│    └── lastUpdate: timestamp
│
├── 📁 chats (Doc ID: conversationId)
│    ├── ephemeralDuration: number [Secondi]
│    └── 📁 messages (Doc ID: auto)
│         ├── sender: string
│         ├── receiver: string
│         ├── text: string (AES)
│         ├── timestamp: timestamp
│         ├── expiresAt: timestamp [Opzionale per effimeri]
│         ├── readReceipts: map<UID, timestamp>
│         ├── deletedFor: array<UID>
│         ├── reactions: map<emoji, array<UID>>
│         ├── replyTo: map<id, senderName, text>
│         ├── edited: boolean
│         └── deleted: boolean
│
└── 📁 groups (Doc ID: groupId)
     ├── name: string
     ├── avatarUrl: string
     ├── createdBy: string
     ├── members: array<string>
     ├── memberNames: map<UID, username>
     ├── ephemeralDuration: number [Secondi]
     └── 📁 chats (Doc ID: auto)
          ├── text: string (AES)
          ├── sender: string
          ├── timestamp: timestamp
          ├── expiresAt: timestamp
          ├── readReceipts: map<UID, timestamp>
          ├── deletedFor: array<UID>
          ├── reactions: map<emoji, array<UID>>
          └── replyTo: map<id, senderName, text>

🧩 Suddivisione dei Componenti JS

chat-sidebar.component.js

Isola la ricerca full-text utenti, il bottone anonimo e l'elenco scrollabile delle conversazioni attive con badge verificato.

chat-messages.component.js

Renderizza l'area centrale, la paginazione incrementale (a blocchi di 5), messaggi multimediali, registratore vocale webm e menu contestuale.

group-create / group-info modals

Gestione separata per il modale di creazione gruppo (con preview blob immediata) e il pannello info/amministrazione partecipanti.

ephemeral-modal.component.js

Modale dedicato alla configurazione personalizzata dei messaggi effimeri con salvataggio sincronizzato sul documento di chat.
